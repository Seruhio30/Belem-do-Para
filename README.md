# Apresentação Web — Belém do Pará

Este projeto é uma apresentação web interativa sobre **Belém do Pará**, criada como uma alternativa mais visual e dinâmica ao PowerPoint.

A apresentação funciona como uma sequência de cenas: o usuário pode avançar com cliques ou com as setas do teclado. Cada cena mostra imagens, títulos e palavras-chave para ajudar durante a fala.

---

## Objetivo

Apresentar Belém do Pará de forma visual, organizada e envolvente, destacando sua relação com:

- rios
- cultura amazônica
- história
- gastronomia
- fé
- natureza
- pontos turísticos
